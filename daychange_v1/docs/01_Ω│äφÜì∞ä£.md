# 오늘을 새롭게 — AI 하루변화 V1 프로젝트 계획서

## 목적
반복되는 일상에 새로운 경험을 추가하고, 하루 5개 외국어 단어의 발음·암기·복습을 돕는 스마트폰 중심 PWA.

## 대상 및 이용 시나리오
개인 사용자 1명용 로컬 시범 버전. 아침에 오늘 활동을 확인하고, 완료 후 체크한다. 외국어 탭에서 언어를 고르고 발음을 들으며 단어를 외운 뒤 기억 여부를 선택한다. 월말에는 기록 탭에서 성취도를 확인한다.

## V1 범위
- 월간 일정 생성: 샘플 활동 12종을 날짜에 순환 배정, 기존 계획 유지.
- 활동 완료/취소 및 월간 달력 표시.
- 영어·일본어·중국어·프랑스어·스페인어별 5단어 제시, 스마트폰 브라우저 음성합성 발음 재생.
- 단어 뜻 가리기/보기, 기억했어요/다시 복습 선택, MySQL 복습 날짜 저장.
- 완료 활동·단어 복습 횟수 통계.
- PWA 매니페스트 및 정적 화면 오프라인 캐시(데이터 API는 온라인 필요).

## V1 제외 / V2 후보
AI 실시간 추천, 지도/날씨 API, 계정별 로그인·권한, 푸시 알림, 음성 인식 발음 채점, 사진 업로드, 일정 수동 교체·편집, 달력 외부 연동, 실시간 여행지 검색은 미구현.

## 개발 구조
스마트폰 브라우저(PWA) → Express REST API → MySQL. 브라우저 SpeechSynthesis API로 발음 재생. 서버 DB 계정은 .env로 관리.

## 일정 및 검수
1단계: MySQL 설치·접속 확인 → 2단계: 초기화/샘플 입력 → 3단계: API 실행 → 4단계: 휴대폰 접속 테스트 → 5단계: 달력·학습·복습 기록 검수.

## 보안/운영
V1은 인증 없는 샘플 사용자(id=1) 데모이므로 인터넷 공개 금지. 집/사무실 동일 Wi-Fi에서 테스트. 외부 배포 전 로그인, HTTPS, 접근제어, CSRF/요청제한, 백업, 개인정보 처리 설계 필수.
