# 시스템 분석표

| 기능 | 입력 | 처리/API | 출력 | DB |
|---|---|---|---|---|
| 월간 일정 조회 | YYYY-MM | GET /api/plan?month= | 달력 | daily_plans, activities |
| 월간 일정 생성 | YYYY-MM | POST /api/plan/generate | 빈 날짜 채우기 | daily_plans, activities |
| 활동 완료/취소 | 일정 ID, status | PATCH /api/plan/:id | 완료 표시 | daily_plans |
| 언어별 단어 | 언어 코드 en/ja/zh | GET /api/words?lang= | 단어 5개 | vocabulary, learning_progress |
| 발음 듣기 | 단어 텍스트, 언어 | 브라우저 SpeechSynthesis | 음성 | 없음 |
| 암기 결과 저장 | 단어 ID, again/good | POST /api/words/:id/review | 복습 예정일 | learning_progress, learning_history |
| 통계 | 사용자 1 | GET /api/stats | 완료·학습 수 | daily_plans, learning_history |

## 복습 알고리즘
- 기억 성공: 첫 성공부터 1, 3, 7, 14, 30일 뒤 복습. 성공 횟수 5 이상이면 30일 주기.
- 다시 복습: 성공 횟수 0으로 초기화하고 1일 뒤 재복습.
- 목록은 복습 기한 도래 단어 → 미학습 단어 → 미래 복습 단어 순서로 5개를 반환.

## 예외 처리
- DB 접속 실패: HTTP 500 + 설정 확인 안내.
- 잘못된 월/언어/복습 값: HTTP 400.
- 존재하지 않는 일정/단어: HTTP 404.
- 발음 음성: 브라우저 및 언어 음성 설치 여부에 따라 품질/재생 가능 여부 달라짐.
