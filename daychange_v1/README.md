# 오늘을 새롭게 — AI 하루변화 V1

스마트폰 친화형 PWA + Node.js/Express + MySQL 8.

학습 언어: 영어(en), 일본어(ja), 중국어(zh), **프랑스어(fr), 스페인어(es)**. 발음 듣기는 기기의 음성 합성 음성 지원 여부에 따라 달라집니다.

## 1. 준비
- Node.js 18 이상
- MySQL 8 서버 실행, 접속 가능한 계정/비밀번호
- Windows PowerShell 또는 VS Code 터미널

## 2. 설치 (Windows PowerShell)
```powershell
cd C:\workspace\daychange_v1
npm install
Copy-Item .env.example .env
notepad .env
```
`.env`에서 `DB_PASSWORD`를 본인의 MySQL 비밀번호로 바꾸세요. 비밀번호나 `.env`는 공개하지 마세요. MySQL 사용자에게 `CREATE DATABASE`, `CREATE TABLE`, `INSERT`, `SELECT`, `UPDATE` 권한이 필요합니다.

## 3. DB 초기화 및 실행
```powershell
npm run init
npm start
```
브라우저에서 `http://localhost:3000`을 엽니다. 처음 실행 후 **월간 달력 → 이 달의 일정 자동 만들기**를 누르세요.

## 4. 휴대폰 접속
PC와 휴대폰을 같은 Wi-Fi에 연결하고, Windows에서 `ipconfig`로 PC의 IPv4 주소를 확인합니다. 휴대폰에서 `http://PC의IPv4주소:3000`으로 접속합니다. Windows 방화벽에서 해당 로컬 포트 허용이 필요할 수 있습니다. **홈 화면 추가(PWA 설치)는 일반적으로 HTTPS 또는 localhost 보안 컨텍스트가 필요**하므로, 다른 기기의 HTTP 주소로 접속하면 설치가 제한될 수 있습니다. 정식 설치는 HTTPS 배포 후 진행하세요.

## 5. 테스트
1. `/api/health`에서 `{"ok":true}` 확인.
2. 월간 일정 생성 후 날짜별 카드 표시 확인.
3. 오늘의 활동 완료 → 달력에서 ✓ 확인.
4. 외국어 탭에서 영어/일본어/중국어 전환, 발음 듣기 확인.
5. 뜻 확인, 기억했어요/다시 복습 누른 뒤 기록 탭에서 복습 횟수 확인.

## 알려진 V1 제한
- 로그인 없는 샘플 사용자 ID=1만 사용합니다. **공용 서버/인터넷에 공개하지 마세요.**
- 월간 활동은 샘플 12개 순환 배정이며, AI가 실시간 생성하지 않습니다.
- 발음은 브라우저 음성합성이므로 설치된 음성/브라우저에 따라 차이가 있습니다. 발음 평가 기능은 없습니다.
- 서비스 워커는 정적 UI만 캐시합니다. DB 기능은 서버 연결이 필요합니다.
- 앱 푸시 알림, 지도, 사진 업로드, 직접 일정 편집, 날씨 연동은 V2 후보입니다.

## V1.1 언어 확장 업데이트
기존 V1을 사용 중이라면 소스 파일을 새 버전으로 교체하고 `npm run init`을 다시 실행하세요. 기존 학습 이력과 일정은 삭제하지 않고 언어 ENUM 컬럼을 확장한 뒤 프랑스어·스페인어 샘플 단어를 추가합니다. 실행 전 DB 백업을 권장합니다.


## V1.2 업데이트 (생활 유형 및 주말 모드)
- 월간 달력에서 **직장인 / 자유시간형**과 **매일 / 주말만**을 선택 후 **설정 저장**을 누릅니다.
- **이 달의 일정 자동 만들기**를 누르면 설정에 맞춰 일정을 생성합니다.
- 기존 일정은 기본 보존합니다. 재생성 체크 시 **미완료 일정만** 새 규칙으로 변경합니다.
- `npm run init`을 다시 실행하면 `user_settings` 테이블이 생성되며 기존 활동·학습 기록은 보존됩니다. 실행 전에 DB 백업을 권장합니다.
- 외국어 5개 언어 학습은 주말 모드와 무관하게 매일 사용 가능합니다.
- 시범판은 사용자 ID 1 고정이며, 인증 및 외부 공개용 보안은 포함되지 않았습니다.
